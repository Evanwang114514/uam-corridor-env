# 走廊 E2 事件版 ACAC

这是 **ACAC 对 UAM 原子决策的适配**，不是原文 MacDec-POMDP 的完整复现。正式环境、旧分钟调度器、昨天的 ACAC 入口和归档不修改。

## 参考与差异

以 LG AI Research 官方提交 [5ca6afb](https://github.com/LGAI-Research/acac/tree/5ca6afb5e00f281c2be1f4cf98f3493c80714d4e) 的 `models.py`、`learner_acac.py`、`popart.py`、`scripts/params/alg/acac.json` 为参照。

| 机制 | 新入口 | 差异 |
|---|---|---|
| Actor | 角色独立，双 128 输入 MLP、64 GRU、64 输出 MLP 和 LayerNorm | 输入是走廊观测，三个合法站点动作，按真实物理分钟编码 2 维正弦时间 |
| Critic | 两套独立历史编码器，128 MLP / 64 GRU；每次动作前按最新角色历史算一个集中式 V | 角色之间不会回填未来观测；非决策计量点沿用已有历史 |
| 集中融合 | 两角色非因果角色注意力，一层 GPT 风格残差块，mean_linear | 用 PyTorch 实现对应拓扑，不直接调用官方改写的 GPT2；禁用 dropout，初始化不声称逐值相同 |
| NoSA | 两角色隐藏态拼接、MLP、Value Head | 对齐官方关闭 Attention 后的分支 |
| 价值训练 | PopArt 自适应标准化与输出保持重标定，集中式归一化平方误差，独立 Adam | 保留走廊学习率和衰减；目标 Critic 每 4 个固定 UAM rollout 硬同步，不是官方每 32 episode |
| 策略更新 | 只对真实且合法动作做独立 PPO-Clip；按事件压紧 GRU 序列并截断反传 | 使用走廊 clip/熵/梯度合同和按事件段 minibatch；不采用作者 epsilon 采样日程或整局更新 |
| Full GAE | 每次动作前估值，目标 Critic bootstrap；真实 tick 换分钟，区间内折扣累计，lambda 按事件 | 同 tick 顺序动作是有序零时长转移；没有把飞行或接驳当作持久宏动作 |
| Micro-GAE | 对同物理轨迹做逐分钟 GAE，将每分钟目标映回动作时刻，扣除此前已产生的奖励 | 时间上限显式保留末段奖励并引导；旧实现的 proper-time-limit 分支在最后一步将优势清零，本实验四臂统一采用新截断口径 |

## 物理与评估边界

- 同时刻先按 ID 完成乘客选站，再允许一次飞机优先级批次；后续在候选和排队状态变化时再触发。底层复用原 _drain、起降/充电/周转处理、可行性和派机。只移除分钟调机门；策略不会抽到非法机场。
- 固定分钟标记只用于记账与 Micro-GAE，不触发 Actor。每格计 195 个 rollout × 5 条轨道 × 2,048 次旧等价推进；截止或完成时的不足一分残段按旧版计为一次推进，同时另报真实 tick、模拟分钟、角色决策和事件数。
- 评估使用同一冻结需求库和策略种子；评估器始终使用本轮事件接口，不在高压临时切换乘客批处理。旧分钟策略作为历史参照，但不能把新旧差异归因于单个算法组件。
- 原生输出保留逐回合 ATT、完成率、固定截止成本、AWT、P90/P95；未全完成的 ATT、AWT 和尾部 ATT 记空。方法内配对按四个训练种子，评估回合不当作独立训练样本。
- 回滚点保存策略、集中/目标 Critic、PopArt、优化器、观测标准化、随机数以及物理队列、时钟和隐藏状态。GPU 内核不承诺跨机器逐位一致。
- 正式入口强制校验同代码、数据、运行库、设备的四臂验收文件。没有验收产物不能进入正式预算；本文件不代表服务器已经启动。
