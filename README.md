# **UAM 联合调度与异步多智能体强化学习研究 README**

## **一、研究背景与交通环境**

本研究围绕城市空中交通（Urban Air Mobility, UAM）中的乘客出发站选择与航空器重定位联合调度问题展开，核心是将乘客侧的出发站分配决策与航空器侧的跨站重定位决策纳入同一个动态决策框架，研究两类决策之间的相互影响及其协同优化机制。乘客选择不同出发站会改变各站点未来的需求分布，而航空器重定位则直接影响不同站点的可用运力，两者共同决定乘客等待时间与系统整体服务效率。因此，本研究将乘客分配和飞机调度置于统一的交通状态、决策过程和奖励目标下进行联合建模，以固定机队和有限交通资源为约束，最小化乘客从出发地到最终目的地的门到门平均出行时间（Average Door-to-Door Travel Time, ATT）。项目以 UAGMC（Unified Air-Ground Mobility Coordination）为重要研究基础，完成其原有联合调度框架的完整复现，并在此基础上建立面向多智能体强化学习的统一实验框架，重点研究不同决策主体如何通过策略交互实现乘客需求与航空器服务能力的动态匹配。

当前 E2 主实验采用三个出发站 V0、V1、V3 和一个目的站 V2，配置固定规模的 eVTOL 机队，并通过调整乘客需求压力构建 1.0×、1.1×、1.2×、1.3×、1.4× 五档实验环境。系统采用分钟级策略决策与更细粒度物理状态推进相结合的运行方式。在每个决策周期内，Passenger Agent 根据当前需求和交通状态选择乘客出发站，Aircraft Agent 则根据航空器位置、可用状态及各站点运力需求决定重定位行为。两类决策共同改变后续系统状态：乘客分配影响各站点的待服务需求，航空器重定位改变未来可提供的运输能力，而航空器的飞行、周转和机场资源占用又进一步影响后续乘客的等待与服务过程。由此形成乘客分配与飞机重定位相互耦合的闭环调度系统。最终评价统一考虑乘客地面接驳、出发站等待、航空器服务、空中飞行及最终离站过程，以完整门到门 ATT 衡量联合调度策略的整体性能。

## **二、人工智能算法与核心方法**

**1. MAPPO（Multi-Agent Proximal Policy Optimization）**

MAPPO 是本研究的基础多智能体强化学习算法，采用集中训练、分散执行（Centralized Training with Decentralized Execution, CTDE）框架，通过集中式 Critic 利用全局状态信息估计团队价值，并使用 PPO 的裁剪策略目标更新 Actor。其优势在于训练机制相对稳定、实现简洁，适合作为 Passenger 与 Aircraft 联合调度任务的基础算法。我们已完成 MAPPO 在 UAM 环境中的迁移与训练，并将其作为后续 ACAC 机制适配和异步 MARL 方法研究的主要对照基线。

论文：Yu et al., *The Surprising Effectiveness of PPO in Cooperative Multi-Agent Games*, NeurIPS 2022。

[论文原文（NeurIPS 2022）](https://proceedings.neurips.cc/paper_files/paper/2022/hash/9c1535a02f0ce079433344e14d910597-Abstract-Conference.html?utm_source=chatgpt.com)

**2. HAPPO（Heterogeneous-Agent Proximal Policy Optimization）**

HAPPO 面向异构智能体协作问题，其核心是 Multi-Agent Advantage Decomposition（多智能体优势分解）与序贯策略更新机制，通过依次更新不同 Agent 的策略，处理异构主体之间的策略依赖关系。与普通 MAPPO 相比，HAPPO 更强调不同智能体策略更新顺序对联合策略优化的影响。

我们已将 HAPPO 迁移至 UAM 联合调度环境，用于研究 Passenger 与 Aircraft 在不同决策职责和动作空间下的协作学习表现。

此外，HAPPO 的序贯优势分解思想也是当前高频决策研究的重要参考。我们希望借鉴其将联合策略优化分解为条件化连续更新的思路，将研究对象从不同 Agent 之间的序贯更新进一步延伸到同一个 Agent 在同一物理时间步内处理多个决策对象的情况。需要注意，两者的决策层次并不相同，我们借鉴的是条件化策略与优势分解思想，而不是直接照搬 HAPPO 的跨 Agent 更新过程。

论文：Kuba et al., *Heterogeneous-Agent Reinforcement Learning*, Journal of Machine Learning Research, 2024。

[论文 PDF（JMLR 2024）](https://www.jmlr.org/papers/volume25/23-0488/23-0488.pdf?utm_source=chatgpt.com)

**3. ACAC（Agent-Centric Actor-Critic）**

ACAC 是本研究目前最重要的异步多智能体强化学习方法。该算法针对不同 Agent 宏动作持续时间不同所引起的异步决策问题，提出 Agent-Centric History Encoder，分别维护和编码不同智能体的历史轨迹，并通过 Attention-based Centralized Critic 融合各 Agent 的历史信息，减少传统 Padding 方式可能引入的异步轨迹错位。

同时，算法设计了适用于异步决策过程的 Macro-GAE，使价值估计与不同智能体的决策时间结构相匹配。其核心价值在于将不同 Agent 的独立历史建模与集中式价值评估结合起来，为异步 MARL 提供了一套 Actor-Critic 学习框架。

论文：Jung et al., *Agent-Centric Actor-Critic for Asynchronous Multi-Agent Reinforcement Learning*, ICML 2025。

[论文原文（ICML 2025）](https://proceedings.mlr.press/v267/jung25a.html?utm_source=chatgpt.com) · [PDF 下载](https://raw.githubusercontent.com/mlresearch/v267/main/assets/jung25a/jung25a.pdf?utm_source=chatgpt.com)

## **三、目前正在推进的研究方向**

### **1. 面向决策机会不对称与不规则性的多智能体强化学习**

**本研究关注不同 Agent 获得决策机会的频率、时间间隔及连续决策结构存在差异时，如何组织历史信息、生成策略动作并完成团队信用分配。**

UAM 中的乘客选站与飞机重定位均为瞬时决策，但不同 Agent 获得合法决策机会的数量和时间间隔并不相同。

现有 UAGMC 及常规 PPO 类方法主要采用分钟级同步决策接口，难以完整处理同一分钟内多个连续发生的有效决策。对于连续数分钟没有合法决策机会的 Agent，传统方法又往往需要通过 Padding 或无效动作进行时间对齐。

ACAC 通过 Agent-Centric History、独立时间戳和 Macro-GAE，在一定程度上解决了异步宏动作的历史组织和时间对齐问题。但对于同一物理时间步内的多次连续决策，以及不同决策频率下的历史信息组织与信用分配，仍然存在进一步研究空间。

目前将该问题分为高频决策、低频决策和混合异步三个方向，其中**高频决策是当前优先推进的研究主线**。

**（1）高频决策（High-Frequency Decision Making）**

**高频决策是指同一个 Agent 在一个物理时间步内连续获得多个有效决策机会，需要依次处理多个决策对象；其核心研究是在同一物理时间步内，多个决策对象应该按照什么顺序进行分配，以及前序动作如何影响后续决策。** 例如，同一分钟内有多个乘客同时需要选择出发站。

这类问题与普通多智能体决策有所不同：多个动作发生在同一物理时间内，但前序动作可能已经改变环境状态和后续决策条件。因此，不能简单地将这些动作视为多个相互独立的分类任务，也不能仅通过统一时间戳将它们合并为一次批量决策。

目前主要围绕两个问题展开。

**① 步内序贯分配与决策顺序优化（Intra-timestep Sequential Allocation and Order Optimization）**

**研究同一个 Agent 在一个物理时间步内需要连续处理多个决策对象时，应该按照什么顺序进行分配，以及前序动作如何影响后续决策。**

例如，同一分钟内有两个乘客需要选择出发站。第一个乘客选择某个机场后，可能改变该机场的待服务需求、后续飞机服务机会以及其他机场之间的相对资源分布。因此，第二个乘客面对的实际决策条件已经发生变化。

我们希望借鉴 HAPPO 的序贯优势分解思想，将多个原子决策组织为条件化的连续决策过程，而不是让所有决策对象独立地基于同一个初始状态输出动作。

对于同一物理时间步内的 $m$ 个决策对象，可以将联合策略表示为：

$$
\pi_\theta(\mathbf a_t\mid s_t,\sigma_t) = \prod_{q=1}^{m} \pi_\theta \left( a_{\sigma_t(q)} \mid s_t,a_{\sigma_t(<q)},h_t^D \right)
$$

其中：

- $s_t$ 表示当前物理状态；
- $\sigma_t$ 表示决策对象的处理顺序；
- $a_{\sigma_t(<q)}$ 表示此前已经执行的动作；
- $h_t^D$ 表示同一物理时间步内累积的决策历史。

这里需要研究两个相互关联的问题：

- **序贯分配：** 后续决策能否根据前序动作及其造成的状态变化进行条件化调整。
- **顺序优化：** 不同决策对象的处理顺序是否会影响最终策略表现，以及能否根据当前状态选择更合理的处理顺序。

同时，将 Dual-stream History Representation 作为辅助机制进行研究：分别组织随物理时间变化的 Physical History，以及同一时间步内随原子决策更新的 Decision History，避免多个乘客的连续决策信息与物理时间历史混淆。

此外，还需要区分输入排列与实际执行顺序。模型不应仅仅因为乘客 ID 或输入排列不同而形成缺乏业务依据的优先级，但真实的序贯执行顺序可以具有实际决策意义。

**② 步内条件化信用分配（Intra-timestep Conditional Credit Assignment）**

**研究同一物理时间步内多个连续动作对未来团队收益的不同贡献，并根据前序决策条件为每个原子动作分配相应的信用信号。**

在连续决策过程中，多个原子动作可能共同影响未来团队奖励，但每个动作对最终结果的实际贡献并不一定相同。

例如，第一个乘客的选站动作可能改善系统整体运力分布，而第二个乘客的动作可能进一步加剧某个机场的需求集中。如果简单地将同一个团队优势分配给两个动作，就难以区分它们各自的条件化贡献。

因此，我们希望建立面向步内连续决策的条件化信用分配机制。

对于前面定义的序贯策略，可以进一步定义条件化动作价值：

$$
Q_q(s_t,a_{\leq q}) = \mathbb E_{a_{q+1:m}\sim\pi_\theta} \left[ Q(s_t,\mathbf a_t) \mid s_t,a_{\leq q} \right]
$$

其中，$Q_q$ 表示已经执行前 $q$ 个原子动作后，对剩余动作继续按照当前策略执行时的期望团队价值。

令：

$$
Q_0(s_t)=V(s_t)
$$

则可以构造每个原子动作的条件化优势：

$$
A_q(s_t,a_{\leq q}) = Q_q(s_t,a_{\leq q}) - Q_{q-1}(s_t,a_{<q})
$$

由此得到：

$$
\sum_{q=1}^{m} A_q = Q(s_t,\mathbf a_t)-V(s_t)
$$

这一分解将联合动作的整体价值变化进一步分配到不同原子决策，使每个动作能够根据此前已经发生的决策条件获得独立的信用信号。

后续重点研究：

- 如何估计不同前缀条件下的动作价值；
- 如何区分决策顺序选择与具体动作的信用；
- 如何将条件化优势融入 PPO 更新，降低多个步内动作之间的信用混淆。

需要强调的是，这里的优势可加性是数学构造的性质，并不意味着 HAPPO 原有的单调策略改进结论可以直接迁移到同一个 Agent 的多对象决策中。

**这两条研究方向具有明确的递进关系：第一条解决多个决策对象如何依次生成动作，第二条解决这些连续动作的团队收益如何分配。** 二者共同构成当前高频决策研究的核心。

**（2）低频决策（Low-Frequency Decision Making）**

**低频决策关注 Agent 在较长时间内没有合法决策机会时，如何利用期间发生的物理变化与队友行为改善自身的历史表示和信用估计。**

例如，Aircraft Agent 可能在飞行或周转期间无法执行新动作，但 Passenger Agent 仍然持续产生新的决策事件。

主要研究三个方面：

- **物理历史演化（Time-aware History Evolution）：** 将决策间隔内的时间变化与队列变化、航空器状态转换、资源释放等物理事件结合，补充现有时间编码和 GRU 历史表示。
- **队友行为历史（Cross-agent Event History）：** 显式记录自身两次决策之间发生的队友动作及其对应的状态变化，研究这些事件能否提供额外的决策信息。
- **异步信用分配（Multi-clock Credit Assignment）：** 比较 Global Macro-GAE、Agent-centric GAE 与 Dual-clock GAE，研究全局事件时钟和角色自身决策时钟对信用传播的不同影响。优先考虑轻量的 Dual-clock λ Gate，在保留全局 TD 残差的情况下，调整不同角色的 $\lambda$ 衰减尺度。

**（3）混合异步（Mixed Asynchronous Decision Making）**

**混合异步关注高频连续决策与低频稀疏决策同时存在时，不同 Agent 的决策过程、历史信息与团队收益如何实现统一建模。**

例如，Passenger Agent 可能在同一分钟内连续处理多个乘客，而 Aircraft Agent 可能经过数分钟才获得一次新的合法决策机会。

后续主要研究：

- **跨角色历史融合：** 统一组织不同 Agent 的物理历史、步内决策历史及队友事件。
- **多时钟价值估计：** 同时考虑物理时间、Agent 自身决策时间和跨角色事件。
- **统一信用分配：** 将同一物理时间内的连续决策与跨多个物理时间步的稀疏决策纳入统一的团队收益分配框架。

最终希望形成面向决策机会不对称与不规则性的统一异步 Actor-Critic 方法，使不同 Agent 在决策次数、时间间隔和决策顺序存在差异时，仍然能够有效组织历史信息、估计团队价值并完成信用分配。

### **2. 面向地空协同的 CAV–UAM 综合交通环境**

**在原有 UAM 联合调度环境中引入有限 CAV 地面接驳运力，将研究问题扩展为乘客选站、地面车辆派单与航空器重定位三个主体之间的联合协同决策。**

CAV 速度设置为 40 km/h，eVTOL 飞行速度为 200 km/h，两类交通工具均采用单座服务，不引入拼车，并设置有限车队规模。系统主要包含三个决策 Agent：

- **乘客选站 Agent（Passenger Selection Agent）：** 乘客产生出行请求后，由该 Agent 根据各出发站的需求和交通状态选择乘客的出发站，决定后续地面接驳目的地。

- **CAV 接客调度 Agent（CAV Dispatch Agent）：** 负责地面车辆派单。CAV 完成上一项任务并重新空闲后，从待服务乘客队列中选择乘客，安排车辆空驶接客，再将乘客送往其选定的出发站。车辆的任务完成时间及乘客抵达时间由车辆当前位置、任务队列和行驶距离共同决定。

- **飞机重定位 Agent（Aircraft Repositioning Agent）：** 根据各出发站的航空器分布、乘客需求和飞机可用状态，决定空闲飞机是否需要跨站重定位，使航空运力能够适应不同站点的需求变化，同时满足飞机周转、起降资源及充电等约束。

三个 Agent 通过乘客需求、车辆接驳和航空器运力形成闭环协作：

1. 乘客首先通过 Passenger Selection Agent 选择出发站。
2. CAV Dispatch Agent 从待服务队列中选择乘客，调度空闲车辆完成空驶接客和载客接驳。
3. 乘客抵达选定出发站后进入候机队列。
4. Aircraft Repositioning Agent 根据各站点的需求和可用运力进行飞机调度与重定位。
5. 航空器在满足服务条件后完成乘客运输，乘客最终离开目的站。

整个系统以乘客门到门平均出行时间（ATT）为统一优化目标：

$$
\mathrm{ATT}=\frac{1}{N}\sum_{p=1}^{N}T_p
$$

其中，每名乘客的完整出行时间包括：

$$
\begin{aligned}
T_p={}&T_{\mathrm{pickup\ wait}} +T_{\mathrm{CAV\ empty}}\\
&+T_{\mathrm{CAV\ loaded}} +T_{\mathrm{vertiport\ wait}}\\
&+T_{\mathrm{flight}} +T_{\mathrm{egress}}.
\end{aligned}
$$

六项依次为：接驳等待、CAV 空驶接客、CAV 载客行驶、机场等待、飞行和最终离站。

通过引入 CAV，原来的乘客选站与飞机重定位问题进一步扩展为地面接驳运力、乘客出发站分配和航空器运力之间的联合决策问题，使不同 Agent 的决策机会、任务完成时间和资源状态形成更加复杂的交互关系。

## **四、实验基线、方法对照与阶段性成果**

**1. UAGMC 交通环境与调度机制复现。**

**已完成 UAGMC 原始交通环境、核心调度流程及主要算法机制的完整复现，并在此基础上建立当前统一的 UAM 联合调度实验框架。**通过对乘客出发站选择、航空器服务和调度流程进行复现，形成了可用于后续算法迁移、机制对照和独立方法研究的实验基础。UAGMC 同时作为重要的原始对照工作保留，后续研究将进一步围绕决策机会结构、历史表示及异步信用分配展开，而不局限于对原始调度策略的简单改进。

**2. MAPPO 与 HAPPO 的环境迁移。**

已完成 MAPPO 和 HAPPO 在 UAM 联合调度环境中的迁移与训练，**建立四训练种子的学习基线**，并统一采用门到门 ATT 作为主要评价指标。相关实验覆盖五档需求压力，能够比较不同 MARL 更新机制在需求增长情况下的性能变化。其中 MAPPO 作为基础 CTDE 对照，HAPPO 则用于验证异构 Agent 序贯更新和优势分解机制在 UAM 场景中的适用性。

实验结果显示，**两种算法在低需求压力下表现接近，但 HAPPO 随需求压力上升出现了更明显的性能退化**：

- **低压力环境（1.0×–1.1×）：** HAPPO 与 MAPPO 基本持平，ATT 分别为 38.60 和 50.65 分钟。
- **中高压力环境（1.2×–1.3×）：** HAPPO 开始明显落后于 MAPPO，1.3× 时 ATT 达到 77.95 分钟，比 MAPPO 高 3.58 分钟。
- **高压力环境（1.4×）：** HAPPO 的 ATT 达到 89.09 分钟，**比 MAPPO 高 5.37 分钟**。

这一结果表明，HAPPO 的异构 Agent 序贯更新机制并未在当前 UAM 任务中带来预期的高压力性能优势，反而表现出更明显的压力敏感性，也为后续从决策机会和序贯信用分配角度研究异构 MARL 提供了实验依据。

**3. ACAC 算法的 UAM 适配版与未适配版实现及实验验证。**

在完成 MAPPO 和 HAPPO 环境迁移后，我们进一步围绕 ACAC 开展算法研究，分别实现了面向 UAM 决策特点进行机制适配的 ACAC-UAM 适配版，以及直接采用 ACAC 原有算法机制、不进行 UAM 专门适配的 ACAC 未适配版。两种实现分别对应任务适配与原始机制直接应用两条路径，**均完成独立训练和五档需求压力评估**。

- **ACAC-UAM 适配版：** 以 MAPPO 为基础，将 ACAC 的核心机制融入 UAM 原有分钟级决策接口，引入 Agent-Centric History、时间编码、注意力历史融合及异步信用分配机制。**完成 Full、NoTE、NoSA 和 Micro-GAE 四臂消融实验**，每种方法均使用 2101–2104 四个训练种子，并完成五档需求压力回放。

- **ACAC 未适配版：** 直接采用 ACAC 原有算法机制，不针对 UAM 的分钟级决策接口及乘客、飞机的具体决策特点进行额外适配，保留 Agent-Centric History、时间编码、Attention-based Critic 和 Macro-GAE 等核心设计。**完成独立的四种子训练**，并在相同 UAM 环境下进行五档需求压力评估。

- **两种实现的对照目的：** 通过将两种实现同时纳入 E2 主对照，研究 ACAC 原始机制直接应用与面向具体交通任务进行机制适配之间的性能差异，分析不同算法组织方式在 UAM 联合调度任务中的适用性。

- **相对 MAPPO 的改善：** **五档压力下 ATT 分别降低 0.39、0.24、0.54、1.68 和 2.35 分钟。**其中 1.3× 和 1.4× 的改善更加明显，表明适配版在较高需求压力下具有更突出的性能优势。

**5. ACAC-UAM 适配版的四臂消融实验。**

下表单独呈现 ACAC-UAM 适配版的 Full 与三个消融方法，并保留普通 MAPPO 作为参照。所有方法均使用 2101–2104 四个训练种子，五档需求压力下均完成全部乘客服务。这里不加入 ACAC 未适配版的结果，以保证消融实验对应同一套算法实现。

| **Full**    | 38.13 ± 0.56     | 50.45 ± 0.91     | **62.74 ± 1.39** | **72.69 ± 1.84** | **81.37 ± 2.70** |
| NoTE（去时间编码） | **37.96 ± 0.38** | **50.02 ± 0.81** | 63.82 ± 2.34     | 78.43 ± 5.19     | 89.46 ± 7.81     |
| NoSA        | 38.58 ± 1.27     | 50.59 ± 0.78     | 63.22 ± 2.14     | 74.69 ± 4.02     | 85.74 ± 5.66     |
| Micro-GAE   | 40.79 ± 0.98     | 52.37 ± 0.31     | 65.70 ± 1.40     | 76.90 ± 1.72     | 86.77 ± 1.85     |

主要消融发现：

- **Full 的高压优势：** ACAC-UAM 适配版 Full 在 1.2×、1.3× 和 1.4× 下均优于普通 MAPPO，其中 **1.3× 和 1.4× 分别改善 1.68 和 2.35 分钟**。
- **时间编码（NoTE）：** 去除时间编码后，算法**在 1.0× 和 1.1× 下反而略有改善，但在 1.2×、1.3× 和 1.4× 下明显退化**。尤其在 1.4× 下，**NoTE 比 Full 慢 8.09 分钟**。这说明时间编码的价值具有需求压力依赖性。
- **注意力融合（NoSA）：** 去除注意力历史融合后，低压力下性能变化较小，但在高压力下退化更加明显。**1.4× 下 NoSA 比 Full 慢 4.37 分钟。**
- **异步信用分配（Micro-GAE）：** **Micro-GAE 在五档需求压力下均落后于 Full，1.4× 下差距达到 5.40 分钟**，说明当前完整信用估计机制具有一定的性能价值。

整体来看，四臂消融结果表明，时间编码、注意力历史融合和信用估计机制的作用并不完全相同，且受到需求压力影响。这些结果为后续进一步研究历史表示与异步信用分配提供了实验依据。

**6. 决策密度差异的对照回放实验。**

在前期实验中，我们发现不同 Agent 获得有效决策机会的频率存在明显差异。同一 Agent 可能在一个物理时间步内连续处理多个乘客，也可能经过多个物理时间步才获得下一次合法决策机会。因此，我们进一步比较不同决策接口下策略行为的变化。

实验发现：

- **决策行为发生明显变化：** 相比 Batch，Single 在 1.1×–1.4× 下**分别改变了 48.76%、53.24%、54.12% 和 56.18% 的乘客选站动作**。
- **交通性能受到决策接口影响：** 两种接口的 ATT 差异随需求压力发生变化，**并没有表现出某一种接口始终占优的规律**。

| 压力   | Batch ATT | Single ATT | ATT 差异（Single − Batch） |
| ---- | --------- | ---------- | ---------------------- |
| 1.1× | 50.454    | 51.310     | +0.856                 |
| 1.2× | 62.456    | 62.989     | +0.533                 |
| 1.3× | 72.409    | 72.541     | +0.132                 |
| 1.4× | 81.256    | 80.419     | −0.836                 |

这一结果说明，决策机会的组织方式不仅影响 Agent 的决策次数，也会改变其策略行为。不同决策密度下的历史信息更新和连续动作之间的依赖关系值得进一步研究，不能简单通过统一时间步或 Padding 将不同决策过程视为相同。

**7. 步内决策顺序与条件化价值的反事实回放实验。**

在上述研究基础上，我们进一步关注同一个 Agent 在同一个物理时间步内连续处理多个乘客时，前序动作是否会改变后续决策，以及不同动作是否应该获得相同的团队信用。

**（1）决策顺序对策略的影响。**

在固定模型和随机数条件下，通过改变乘客输入顺序与实际执行顺序，发现当前策略存在明显的排列敏感性。

在 1.4× 压力下：

- 改变输入顺序后，**42.92% 的乘客选站动作发生变化，平均绝对 ATT 差异为 1.055 分钟**。
- 改变实际执行顺序后，**平均绝对 ATT 差异达到 1.242 分钟**。

这说明同一时间步内多个决策对象的处理顺序会影响后续策略行为，如何合理组织步内决策顺序具有进一步研究价值。

**（2）前序动作对后续决策的影响。**

通过对同一时间步内两个乘客的不同动作组合进行反事实比较，进一步发现前序动作能够显著改变后续乘客的最优选站决策。

| 压力     | 前序动作改变后续最优动作的比例 | 存在实质性价值差异的比例 | 事后最优联合动作的 ATT 优化空间 |
| ------ | --------------- | ------------ | ------------------ |
| 1.1×   | 89.58%          | 70.83%       | 0.367 min          |
| 1.2×   | 91.67%          | 85.42%       | 0.607 min          |
| 1.3×   | 91.67%          | 85.42%       | 0.775 min          |
| 1.4×   | 91.67%          | 82.29%       | 1.130 min          |
| **总体** | **91.15%**      | **80.99%**   | **0.720 min**      |

其中，实质性价值差异采用较严格的判断标准：不同前序动作对应不同的后续最优动作，并且相互选错所造成的代价均超过全回合平均 ATT 的 0.1 分钟。

这意味着，**即使物理时间没有推进，前序乘客的选站动作也可能改变后续乘客的最优决策。**同一物理时间步内的多个原子动作并不是相互独立的分类任务，而是具有明显的序贯条件依赖关系。

需要说明，**表中的 ATT 优化空间是反事实条件下的事后最优结果，并不代表当前策略已经实现了相应的性能提升。**

**（3）步内条件化信用分配。**

进一步分析发现，**不同乘客的动作虽然共同影响团队奖励，但其实际贡献方向并不总是一致。**

| 指标                                       | 实验结果       |
| ---------------------------------------- | ---------- |
| 同组两个 Prefix Advantage 符号相反的比例            | **34.38%** |
| Shared Advantage 与 Prefix Advantage 相关系数 | −0.004     |
| CF 与 Prefix Advantage 相关系数               | 0.886      |
| CF 与 Prefix 首动作 Top-1 一致率                | 75.78%     |
| 前缀优势分解最大加性误差                             | 0          |

上述优势相关性采用相同的原训练折扣率计算。

这说明，直接将同一个团队优势分配给同一时间步内的多个动作，可能无法充分表达各个原子决策的条件化贡献。例如，前一个乘客的动作可能有利于团队，而后一个乘客的动作反而可能降低团队收益。

**阶段性判断：**

上述实验为当前高频决策研究提供了直接依据：

- 前序动作会改变后续决策的最优选择，因此需要研究**步内序贯分配与决策顺序优化。**
- 不同原子动作的团队贡献可能存在差异，**因此需要研究步内条件化信用分配。**

这也构成了当前项目从常规多智能体协同调度转向高频决策机制研究的主要动机。
